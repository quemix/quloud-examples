==============================
計算条件と再現手順
==============================

この例題の数値は、WSL上のDockerでGROMACS 2026.2を実行して得たものです。
Quloudの画面から投入したジョブではありません。
Quloud用のCIF入力・トポロジー生成・ローカル実行ランナーを用いました。
記事のArのP–V計算と5気体比較は、標準イメージの混合精度で実行しています。
同じGROMACS 2026.2の倍精度ビルドによる計算も、数値条件への依存性を調べる参考値として保存しています。
モデルYAMLとトポロジー生成処理は共通です。
Quloudの実画面での再実行と、本番環境との出力の照合は未確認です。

.. important::

   第2回は分子の重心の速さと、5気体がいずれも約1 atmになる大まかな比較に範囲を絞っています。
   気体ごとの1%未満の圧力差は数値条件によって動くため、物性の差とは解釈しません。
   Quloud実画面での投入・編集・出力回収は未確認であり、公開前のレビューを残したプレビューです。

入力とモデル
============

計算セルは3方向周期境界の立方体です。Arは1,000原子、H₂・N₂・O₂は各2,000原子、
CO₂は3,000原子で、いずれも1,000分子に相当します。
ランダムな分子の中心と向きを固定シード1101、2202、3303で生成しました。
異なる分子の中心間を0.8 nm以上離し、周期境界を含む原子間距離も別に調べています。
分子の識別後の原子順・分子数・質量・電荷・拘束は、実際のTPRと生成済みITPで確認しました。

.. note::

   登録CO₂モデルは、文献の完全な剛体TraPPEモデルをそのまま実装したものではありません。
   数値積分上の理由から角度に調和ポテンシャルを使っており、500 kJ/mol/rad²は文献値ではありません。
   N₂・O₂の結合も登録時に剛体化されています。
   ここで比較するのは、これらの登録モデルを用いた古典MDです。
   とくにH₂の回転・振動の量子効果まで再現する計算ではありません。

Quloudでの設定（実画面では未確認）
==================================

以下はソースの読み取りで確認した編集経路です。実画面で操作確認した手順ではありません。
ローカルでは、この編集後に相当する入力をQuloud用ランナーで実行しています。

`Quloudオンラインマニュアル <https://manual.quloud-platform.quemix.com/>`__
のMaterialのファイルアップロードでCIFを登録し、GROMACSの古典分子動力学を選びます。
温度273.15 K、アンサンブルNVTにします。NPTは用いません。
ArのP–V計算では時間刻み2 fs、220,000ステップ、V-rescale、温度緩和時間0.1 psを使います。
計算開始前のRegistered状態で、Jobのファイル一覧から生成された ``nvt.mdp`` を開いて編集します。
画面のJob設定を変更するとMDPが再生成されるため、ファイルの追記は最後に行い、保存後に内容を確認します。
新しいMDPをアップロードする必要はありません。

ArのP–V計算で追記・確認する出力設定は次のとおりです。
同じキーがあれば行を置き換えてください。

.. code-block:: ini

   gen-seed = 1101
   ld-seed = 101101
   nstcalcenergy = 50
   nstenergy = 50
   nstlog = 5000
   nstxout-compressed = 500
   nstxout = 500
   nstvout = 500
   comm-mode = Linear
   nstcomm = 100
   rlist = 1.2
   rcoulomb = 1.2
   rvdw = 1.2
   DispCorr = no

シード2202と3303では、 ``gen-seed`` と ``ld-seed`` をそれぞれ2202と102202、3303と103303にします。
入力の ``coulombtype = PME`` は、電荷のないAr・H₂・N₂・O₂でコンテナが ``Cut-off`` に変更します。
正味電荷が0でも各原子に電荷を持つCO₂ではPMEが維持されます。
比較に使うのはアップロード時のMDPだけでなく、実行後の ``mdout.mdp`` とTPRの設定です。

5気体の比較では、分子内運動と並進の熱の分配を整えるため、
RegisteredのJobで次も変更します。これはGROMACSの確率的動力学によるNVTです。

.. code-block:: ini

   integrator = sd
   tcoupl = no
   tc-grps = System
   ref-t = 273.15
   tau-t = 0.1
   pcoupl = no

``tcoupl = no`` でも、 ``sd`` 自体の摩擦と乱数が熱浴を表します。
今回の軌跡を使って実在気体の拡散係数や衝突時間を議論することはしません。
H₂は0.5 fs、880,000ステップにし、出力間隔は ``nstcalcenergy = nstenergy = 200`` 、
``nstxout = nstvout = nstxout-compressed = 2000`` 、 ``nstlog = 20000`` とします。
ほかの4気体は2 fs、220,000ステップです。
どちらも全体440 psのうち、40 psより後の400 psを測定区間にします。

.. important::

   この記事の混合精度での比較を再現するときは、時間刻みをH₂は0.5 fs、ほかは2 fsにし、表の値より小さくしないでください。
   拘束力による圧力の数値誤差は、刻みを小さくするだけでは改善せず、むしろ大きくなる条件があります。
   これは今回の条件を再現するための指定で、圧力が時間刻みについて収束していることを意味しません。

CO₂はCoulomb項のカットオフとPME格子間隔をともに5倍にしています [4]_ 。
LJ項のカットオフ1.2 nmは変えません。

.. code-block:: ini

   coulombtype = PME
   rlist = 6.0
   rcoulomb = 6.0
   rvdw = 1.2
   fourierspacing = 0.6
   pme-order = 4
   ewald-rtol = 1e-5
   lincs-order = 4
   lincs-iter = 1

この調整は数値誤差が0になることを意味しません。
倍精度・LINCS次数8・反復2の参考条件で、元の1.2 nm／0.12 nm設定と、
4つの同一状態からそれぞれ10ステップ進める比較を行いました。
圧力差は各短区間の平均で−0.00070〜−0.00082 bar、瞬間値では最大0.00083 barでした。
一方向の差があり、参考値の統計標準誤差と同程度です。
400 ps平均の系統誤差の上限を与える検証ではなく、長時間のPME収束確認は残っています。

全5種で記事の混合精度SDには ``lincs-order = 4`` 、 ``lincs-iter = 1`` を使います。
次に示す倍精度CO₂の参考値だけは次数8・反復2です。

CO₂では倍精度への変更とLINCS条件の変更が同時に入っています。

H₂の0.25 fs対照も、混合精度400 psで1.04090 ± 0.00077 bar、倍精度100 psで1.01504 ± 0.00105 barです。

各入力と出力を一対一に保証できないため解析から除外しました。
記録だけから実際の上書きの有無は確定できないため、正常終了の印があるものも採用していません。
Ar・O₂を各3シード、新しい出力先で一度ずつ再計算した結果が、今回の記事の値です。

出力と解析
==========

Jobの一括ダウンロードで得たZIPを一つのフォルダへ集め、次のスクリプトに渡します。
ZIPの名前は問いません。解析はファイルの内容から気体・分子数・質量・体積を読み取ります。
必要な出力は ``nvt.edr`` 、 ``nvt.tpr`` 、 ``nvt.trr`` 、 ``nvt.log`` です。
座標のみのXTCやQuloudJob.mdでは、ここで行う保存速度の解析を代替できません。
今回のNVTのEDRにはVolume項がないため、体積はTRRのセル行列の行列式から読みます。
全保存フレームでの一定性と、TPRおよびGROとの一致を確認しています。

* :download:`analyze_gases.py <scripts/analyze_gases.py>` ：EDRの抽出、TPRの分子ID・質量とTRRの速度による重心速度解析。
* :download:`theory.py <scripts/theory.py>` ：MDと独立した理想気体の予測。
* :download:`make_figures.py <scripts/make_figures.py>` ：抽出データから図と集計を生成。

3本のスクリプトは同じフォルダへ保存してください。
全6図を出力ZIPから作る場合は、混合精度の本文用33計算に加え、
5気体×3シードの倍精度参考計算の出力も必要です（合計48計算）。
倍精度は標準Quloudから取得できた出力ではなく、今回のローカル検証用の結果です。
既存の図を再生成する場合は、配布済みの集計データを使えます。

.. code-block:: bash

   python analyze_gases.py downloaded_zips --out analysis
   python theory.py --out analysis
   python make_figures.py analysis --figures figures

Python 3、NumPy、Matplotlib、GROMACS 2026.2を使います。
理論値は、SIで厳密に定義されたBoltzmann定数とAvogadro定数 [5]_ の積から気体定数を求めています。
``gmx`` が別名なら ``--gmx gmx_mpi`` のように指定できます。
配布済みのCSVから図だけを作り直す場合は、 ``analysis_csv.zip`` を展開して
``python make_figures.py analysis --figures figures`` を実行します。この場合、GROMACSは必要ありません。
TRRから保存された速度を読み、分子ごとに
:math:`\boldsymbol{v}_{\mathrm{COM}}=\sum_i m_i\boldsymbol{v}_i/\sum_i m_i`
を計算します。位置の有限差分は使いません。
結合長の検査だけに周期境界の最小像を用いています。

生データの ``energy_raw.csv`` と ``velocity_raw.csv`` 、ブロック長ごとの ``block_scan.csv`` 、
各計算の ``summary.json`` を出力します。
圧力の単位はbar、温度はK、エネルギーはGROMACSのkJ/mol表示です。
エネルギーは1分子あたりに割った値ではありません。
TRRの速度の単位nm/psを1,000倍してm/sへ換算しています。
``velocity_raw.csv`` の二乗平均を時間平均した平方根が記事の二乗平均平方根速度です。
原子ごとの速さや、速さそのものの算術平均とは異なります。

統計誤差と有限サイズ
====================

圧力と速さの二乗について、測定区間を5、10、20、40、80 psのブロックに分け、
ブロック平均の標準偏差をブロック数の平方根で割った平均の標準誤差を求めます。
短い対照計算では、4ブロック以上を取れるブロック長だけを使います。
各計算ではこの5通りのうち最大値を使います。
3シードをまとめた誤差は、シード間の標準誤差と、各シード内のブロック誤差を伝播した値の大きい方です。
図の誤差棒は1標準誤差で、95%信頼区間ではありません。
3シードしかないので、小さな差の検出には向きません。

P–Vフィットは一辺30、33、33.3879144、36 nmの4点について :math:`P=a/V_m+b` の係数を両方自由に決めます。
推定体積は :math:`a/(1.01325-b)` です。
同じシードを体積間で共有する相関を、同時刻のブロックとシード間の共分散で伝播します。
この誤差には、相互作用モデル、積分条件、有限サイズによる偏りは含めません。

全系の重心運動を除くと3自由度が失われ、単原子の理想系では圧力の期待値が
:math:`(N-1)/N` 倍になります。1,000粒子では0.1%です。
この式は重心速度を厳密に0に保つ場合のものです。
確率的動力学では乱数によって除去の間にも重心速度が生じるため、実際の重心速度も保存速度から検査しています。
今回のSDのEDR平均温度は273.28〜273.43 Kで、出力をそのままCSVへ記録しています。
TPRで温度計算に使う自由度はArが2,997、二原子分子が4,997、CO₂が6,997です。
拘束だけを除いた自由度（それぞれ3,000、5,000、7,000）で同じ運動エネルギーを換算すると、各気体とも273.15 K付近になります。
この換算値と元の温度は ``temperature_dof.csv`` に分けて保存しています。
第1回のAr（V-rescale、33.3879 nm、1.01184 bar）と第2回のAr（SD、1.01260 bar）の差にも関係します。
V-rescaleでは重心を除いた2,997自由度に温度を合わせるのに対し、SDでは重心除去の間にも乱数による全系の運動が生じます。
SDの保存速度では全系重心の速さが最大約27〜33 m/sあり、温度を3,000自由度で換算すると273.16 K付近になります。
第1回の単純な0.1%補正を、そのまま第2回へ当てはめることはできません。
分子数2,000のArも同じ数密度で比較し、分子数の影響を調べています。
文献値との細かい差をモデル固有の非理想性と呼ぶ前に、こうした影響を区別する必要があります。

H₂では0.5 fsから0.25 fsへ、CO₂では2 fsから1 fsへ変えると、圧力のずれは数%まで増えました。
今回の混合精度の圧力は、時間刻みについて収束した数値ではありません。
図の倍精度系列は、別の数値精度で得た参考結果を並べたもので、混合精度の刻み依存性を補正した値ではありません。

測定区間の前半・後半の温度と圧力、結合長、CO₂の角度、全系の重心速度は
``stability.csv`` に保存しています。
採用した5気体の各シードについて、前半と後半の平均圧力の差の絶対値は最大約0.0028 barでした。
ブロック長ごとの誤差は ``block_scan.csv`` で確認できます。
温度制御中は熱浴とエネルギーを交換するため、全エネルギーの保存を合否基準にはしていません。
温度・エネルギーの時系列は ``energy_raw.csv`` に分けて保存しています。

Arのずれの独立予測
==================

ArのLJポテンシャルを :math:`u(r)=4\epsilon[(\sigma/r)^{12}-(\sigma/r)^6]` とし、
カットオフ :math:`r_c=1.2` nmでポテンシャルをシフトした二体分布を使います。
圧力に寄与する第二ビリアルの係数を次の数値積分で求めます。

.. math::

   \begin{aligned}
   B_{2,P}&=-\frac{2\pi N_A}{3RT}
     \int_0^{r_c}r^3 u'(r)g(r)\,dr,\\
   g(r)&=\exp\!\left[-\frac{u(r)-u(r_c)}{RT}\right].
   \end{aligned}

式のエネルギーと気体定数は同じ単位系にそろえます。
``theory.py`` はモデルのσ、ε、カットオフだけを入力とし、MD圧力を読みません。
圧力用の係数は約−15.772 cm³/molで、積分点数を50,000から100,000へ増やした差は約10⁻⁹ cm³/molでした。
ポテンシャルをカットオフで0へシフトし、力をそこで打ち切ったモデルの係数です。
打ち切りのないLJの第二ビリアルとは区別しています。

希薄な二体近似と全体の重心運動の除去を組み合わせた予測は、
各体積の実測平均温度を :math:`\overline{T}` として、次の式です。

.. math::

   \begin{aligned}
   P_{\mathrm{pred}}&=\frac{RT}{V_m}
      \frac{N-1}{N}\left(1+\frac{B_{2,P}}{V_m}\right)
      \frac{\overline{T}}{T},\\
   T&=273.15\ \mathrm{K},\quad N=1000.
   \end{aligned}

温度の小さな違いにはこの式の一次補正を使い、係数の温度微分や三体以上の項は含めていません。
``argon_virial.json`` に係数と積分条件、``argon_deviations.csv`` に6体積の予測・測定・残差を保存しています。
圧力を自由フィットした係数とは独立した比較です。

時間相関と追加の対照
====================

``autocorrelation.csv`` に圧力の積分自己相関時間を併記しています。
標本間隔は0.1 psで、自己相関の隣接2項の和が初めて非正となる前までを積分しました。
独立な標本なら積分時間は標本間隔の半分になる定義です。
今回の採用計算の推定値は約0.062〜0.133 psで、5 ps以上のブロックより短い値でした。
短い記録からの推定であり、平衡化や全ての遅い変動の不存在を証明する指標ではありません。
80 psブロックは5個しかないため、その誤差推定が粗い点にも注意してください。

二原子分子の速さがそろって理論値より約0.07%低い理由の切り分けは未完了です。
速度の保存時刻と拘束・有限時間刻みの影響も含めた対照が必要で、熱浴の種類だけを原因と決めていません。

Arのシード1101では、リスト更新を10ステップ、リスト半径1.3 nm、
``verlet-buffer-tolerance = -1`` に固定した440 psの対照も行いました。
ログでも0.1 nmのバッファを確認し、40〜440 psの平均圧力は1.01145 ± 0.00062 barでした。
元の自動調整（100ステップ、バッファ0）での1.01192 ± 0.00066 barとの差は、統計誤差より小さい値です。
1条件の確認であり、他の気体や密度すべてのリスト収束を保証するものではありません。

N₂の倍精度SDでは、熱浴の緩和時間を0.1 psから10 psへ弱めた対照を追加しました。
全640 psのうち最初の240 psを除いた400 psで、圧力は1.01492 ± 0.00444 bar、
重心rms速さは493.72 ± 1.11 m/sでした。
同シードの0.1 ps条件は1.01162 ± 0.00070 bar、493.14 ± 0.32 m/sで、差は合成した統計標準誤差以内でした。
弱い熱浴では相関時間も長く、より長い測定が必要です。
CO₂での同じ弱熱浴対照は未実施で、すべてのモデルが熱浴の強さに依存しないことを示したわけではありません。
これらの条件と数値は ``review_controls.csv`` にも記録しています。
